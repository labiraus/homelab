The five-section IA, existing editorial tokens, reserved composer, focus-managed

Desktop/mobile rendering and tests are recorded below after actual execution.

## Correction order and scope

1. Repair Create's inline working artefact, stable shared-result identity and
   explicit save/review return path. Reuse the retained record editor for detailed
   fields; generated and edited operations stay noncanonical.
2. Repair Ask's source previews, exact pins and follow-up continuity. Keep all
   generation behind the existing authenticated API and capability gates.
3. Verify navigation, uncertainty/retry, reader suggestions, local receipts and
   responsive containment. Retain Explore, story and governance regression gates.
4. Defer automatic focused graph composition, comprehensive consequence analysis,
   persistent task-to-proposal links and full editable-candidate version history.
   The present APIs do not supply those as first-class response/task objects.

## Experience decision record

The supported intention is to understand a cited subject, then develop and edit a
candidate in the same conversation before explicitly saving a reviewed proposal.
Only scoped published reads are canon. AI answers are interpretations; generated
and edited operations are drafts. Saved conversations use actual server capability;
unsaved candidate edits remain local component state and need an explicit save
before refresh/world exit. Existing device saves retain their separate queue and
identity semantics. Keyboard controls and narrow layouts use the existing shell
and tokens. Review/publication authority remains entirely with external Go.
